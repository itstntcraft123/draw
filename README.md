# draw something

Draw something on a graph using coordinates!

## Usage

See installation below. If you are on mobile, rotate your device to landscape.

Type coordinates like (x, y) row by row into the input field to draw points. These are automatically connected. Type STOP or END to break the line.

## Installation

Check out the [demo website](https://draw-5yc.pages.dev/) to try it. To run locally, `git clone` this repo, then open `index.html` in your browser. This requires an internet connection for p5.js. If you want to run this without internet, download p5.min.js 2.0.5 and change script src (line 6 in `index.html`) to your file.

## How it works

This project was made using p5.js 2.0.5 and HTML. It utilizes CSS scaling to fit your screen, however this may not work well on mobile devices.
